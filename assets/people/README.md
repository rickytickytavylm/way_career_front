# Фотографии профилей

В demo mode используются оптимизированные изображения Unsplash, URL которых собраны в `server/data.js`.

Для замены на локальные материалы:

1. положите WebP/JPEG-файлы в эту папку;
2. замените значения массива `photos` на пути вида `/assets/people/maria.webp`;
3. сохраните квадратный или портретный кроп не меньше 640 px.
